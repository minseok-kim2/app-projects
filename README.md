# app-projects

비움, 밀퀘, 교집합 세 앱 프로젝트를 한곳에서 관리하는 저장소입니다.
main 브랜치에는 저장소 설명과 최종 결과물만 두고, 실제 개발은 프로젝트별 브랜치에서 합니다.

## 프로젝트

- **비움 (Bium)**: 정보에 수명을 붙여 관리하는 메모 앱
- **밀퀘 (MilQuest)**: 군 복무를 RPG처럼 풀어낸 자기계발 앱
- **교집합**: 팀 의사결정에서 모두가 받아들일 수 있는 합의안을 만들어주는 서비스

## 브랜치

| 브랜치 | 용도 | 폴더 |
|---|---|---|
| `main` | 저장소 설명, 프로젝트별 README, 최종 APK | `apk/` |
| `bium` | 비움 개발 | `front/`, `back/` |
| `milquest` | 밀퀘 개발 | `front/`, `back/`, `ai/` |
| `consensus` | 교집합 개발 (바이브코딩) | 따로 나누지 않음 |

## 작업 규칙

- main에는 직접 push하지 않습니다. 각자 맡은 프로젝트 브랜치에서만 작업합니다.
- 최종 APK는 `apk/` 폴더에 올립니다. 파일이 100MB를 넘으면 Releases에 올리고 링크만 남깁니다.
- 커밋 메시지는 무엇을 했는지 알아볼 수 있게 짧게 적습니다.
